## 2. Installation

1. Copy `{{ZIP_NAME}}` to the server and verify its checksum against `{{ZIP_NAME}}.sha256`:
   ```powershell
   (Get-FileHash .\{{ZIP_NAME}} -Algorithm SHA256).Hash
   ```
2. Extract it to a directory such as `D:\Apps\{{NAME}}` (paths with spaces are supported).
   If the ZIP was downloaded, unblock it first: `Unblock-File .\{{ZIP_NAME}}`.
3. Restrict write access to the directory to administrators/deployment accounts.
4. Run the verification:
   ```powershell
   powershell -NoProfile -ExecutionPolicy Bypass -File D:\Apps\{{NAME}}\verify.ps1
   ```
5. Run the application:
   ```bat
   {{RUN_COMMAND}}
   ```

For scheduled tasks, call the launcher with its absolute path. The working directory is handled by the launcher.
