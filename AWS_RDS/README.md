# AWS RDS Babelfish Scripts

This repository contains a set of Python scripts to manage AWS RDS Aurora clusters, with a focus on Babelfish for PostgreSQL.

## Scripts

### 1. `aurora_rds_manager.py`

**Purpose:**

This script provides an interactive command-line interface to manage AWS RDS Aurora clusters. It allows you to:
- List clusters matching a specific name pattern.
- Get the status of one or all matching clusters.
- Start one or all matching clusters.
- Stop one or all matching clusters.

**How to use:**

Run the script from your terminal:
```bash
python aurora_rds_manager.py
```
The script will prompt you to enter your AWS credentials, a cluster name pattern to search for, and then show a menu with the available options.

**Example:**
```
python aurora_rds_manager.py
Enter AWS Access Key: YOUR_ACCESS_KEY
Enter AWS Secret Key: YOUR_SECRET_KEY
Enter AWS Session Token: YOUR_SESSION_TOKEN
Enter AWS Region (e.g., us-east-1): us-east-1
🔐 Getting AWS credentials and initializing RDS client...
🔍 Enter cluster name pattern to search: my-cluster

🔍 Matching Aurora Clusters:
1. my-cluster-1 (available)
2. my-cluster-2 (stopped)

📋 Menu:
1. Get status for cluster(s)
2. Start cluster(s)
3. Stop cluster(s)
4. Exit
Select an option (1-4): 1
Apply to all matching clusters? (y/n): n
Enter cluster name from the list above: my-cluster-1
🔎 my-cluster-1: available
```

### 2. `extract_babelfish.py`

**Purpose:**

This script extracts the configuration of a Babelfish Aurora cluster and saves it to a JSON file. This is useful for backing up the cluster's configuration or for recreating the cluster later.

**How to use:**

Run the script from your terminal:
```bash
python extract_babelfish.py
```
The script will prompt you to enter your AWS credentials and the ARN of the Babelfish Aurora cluster.

**Example:**
```
python extract_babelfish.py
Enter AWS Access Key: YOUR_ACCESS_KEY
Enter AWS Secret Key: YOUR_SECRET_KEY
Enter AWS Session Token: YOUR_SESSION_TOKEN
Enter AWS Region (e.g., us-east-1): us-east-1
Enter the Babelfish Aurora cluster ARN: arn:aws:rds:us-east-1:123456789012:cluster:my-babelfish-cluster
Configuration saved to Clusters\babelfish_config_d4f597fc224a718c60e1444448d75e8f.json
```

### 3. `recreate_babelfish.py`

**Purpose:**

This script recreates a Babelfish Aurora cluster from a JSON configuration file generated by `extract_babelfish.py`.

**How to use:**

Run the script from your terminal:
```bash
python recreate_babelfish.py
```
The script will prompt you to enter your AWS credentials and the path to the JSON configuration file.

**Example:**
```
python recreate_babelfish.py
Enter AWS Access Key: YOUR_ACCESS_KEY
Enter AWS Secret Key: YOUR_SECRET_KEY
Enter AWS Session Token: YOUR_SESSION_TOKEN
Enter AWS Region (e.g., us-east-1): us-east-1
Enter the path to the configuration JSON file: Clusters\babelfish_config_d4f597fc224a718c60e1444448d75e8f.json
Cluster my-babelfish-cluster created successfully: ...
DB Instance my-babelfish-cluster-instance-1 created successfully: ...
```

### 4. `delete_babelfish.py`

**Purpose:**

This script deletes a Babelfish Aurora cluster.

**How to use:**

Run the script from your terminal:
```bash
python delete_babelfish.py
```
The script will prompt you to enter your AWS credentials and the ARN of the Babelfish Aurora cluster to delete.

**Example:**
```
python delete_babelfish.py
Enter AWS Access Key: YOUR_ACCESS_KEY
Enter AWS Secret Key: YOUR_SECRET_KEY
Enter AWS Session Token: YOUR_SESSION_TOKEN
Enter AWS Region (e.g., us-east-1): us-east-1
Enter the Babelfish Aurora cluster ARN to delete: arn:aws:rds:us-east-1:123456789012:cluster:my-babelfish-cluster
DB Cluster arn:aws:rds:us-east-1:123456789012:cluster:my-babelfish-cluster deletion initiated: ...
```

### 5. `extract_babelfishold.py`

**Purpose:**

This script appears to be an older, possibly deprecated, version of `extract_babelfish.py`. It has a similar purpose of extracting a Babelfish cluster's configuration. It is recommended to use `extract_babelfish.py` instead.

## Utility Modules

### `utils/aws_credentials.py`

This module provides the `get_aws_client` function that prompts the user for AWS credentials (access key, secret key, session token, and region) and returns a `boto3` client for a specified service.

### `utils/colors.py`

This module provides functions to print colored text to the console, used to improve the readability of the scripts' output.
